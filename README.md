# PDM_P3 - Pokédex Android

Tarea 3 de Programación de Dispositivos Móviles.

Aplicación Android que funciona como una **Pokédex** (enciclopedia de Pokémon). Esta aplicación integra las dos vistas desarrolladas en la Tarea 2:

- **Vista 1:** Muestra los Pokémon utilizando la API de [PokeAPI](https://pokeapi.co/) para obtener los primeros 151 Pokémon.
- **Vista 2:** Muestra información detallada del Pokémon seleccionado, incluyendo estadísticas y características principales.

Además, se realizaron algunas mejoras visuales para una mejor la experiencia del usuario.
